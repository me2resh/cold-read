# Examples

Four sample reads, one per lens, showing the shape of the output. The companies are samples (each name was checked against the web when written and matched no company) and the figures are illustrative; links are placeholders. The marks (✅ 🟡 ❔) are used exactly as the skill requires, so you can see how a real note reads.

| Lens | File | The one question |
|---|---|---|
| Deal | `deal-hollowmere-kerbline.md` | What happens to the acquired engineering team, and was the price cheap? |
| Join | `join-platterloop.md` | What would a Head of Engineering inherit, and who will I meet? |
| Invest | `invest-lanternglass.md` | Is this a three-year hold? |
| Position | `position-pedalgrove.md` | Who wins the UK market, and what would change the ranking? |
