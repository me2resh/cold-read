# Examples

Four worked outputs, one per lens. **Every company, person, number and source in these files is invented** to show the shape of the output; nothing here describes a real company. Links are placeholders. The marks (✅ 🟡 ❔) are used exactly as the skill requires, so you can see how a real note reads.

| Lens | File | The one question |
|---|---|---|
| Deal | `deal-meridian-parcelwise.md` | What happens to the acquired engineering team, and was the price cheap? |
| Join | `join-tablelight.md` | What would a Head of Engineering inherit, and who will I meet? |
| Invest | `invest-lumenary.md` | Is this a three-year hold? |
| Position | `position-pedalpost.md` | Who wins the UK market, and what would change the ranking? |
